保留解释与只留结论：
一次小规模 SFT 对照

2026-09-29 · Qiang (Nate) Zhang · Qwen2.5-0.5B-Instruct / LoRA

在这次 0.5B 模型的小实验里，保留解释组的同模板测试得分为 32/36 和 35/36，只留结论组为 16/36 和 17/36。这里只报告这批题上的结果。样本很少，解释组接受的监督 token 约为另一组的 5.9 倍，不能据此证明“删解释会让模型普遍失去推理能力”。

两组到底改了什么

同一批 96 道英文训练题，两组最终数值都正确。一组保留计算步骤或条件判断，一组只有 Answer: 数值.。提示词要求以 Answer 数值收尾，没有要求必须解释或必须简答。

题目包括数量计算、排除运费的满减门槛、先增后减的百分比变化，每类 32 道。测试使用相同模板下未参与训练的 36 个参数组合，另加 12 道简单事实与算术探针。这不是新题型泛化测试，也不是通用能力基准。

每个随机种子都从同一个原始模型和新初始化的 LoRA 开始，训练三轮、每批 4 条，共 72 步；两组配对使用相同的样本顺序。只监督 assistant 部分，训练不截断。固定取最后一轮，没有依据测试分数挑选检查点。完整设置见实验协议。

原模型的 0/36，不等于一道都不会算

原模型在主实验的 36 道同模板题上没有通过严格评分，但其中 23 道没有解析出 Answer 数值，17 道达到 128-token 上限。这个分数包含格式要求和生成预算的影响，不能把它解读成微调带来了从零开始的推理能力。

例如 inventory-8-11-2，原模型已经算出 8 × 11 − 2 = 86，并把 86 放进了公式框；因为没有输出 Answer: 86，仍被记为未通过。百分比题则有 12/12 碰到了长度上限。因此，这里的主要比较是两种训练目标之间的表现，不是用这个基线制造“巨大提升”。

这次能留下什么结论

这组小实验观察到了不同训练答案带来的结果差异，也暴露了评测实现对结论的影响。它还不足以区分：差异来自中间步骤、任务信息重复、监督 token 预算，还是这些因素共同作用。

两组虽然都训练 72 步，监督 token 分别是 13,974 和 2,349；损失又是在每批有效 token 上取平均。解释组不仅“多说了几句”，还多接受了任务相关监督。数据使用固定模板、英文、小模型和两个种子，也都限制了外推范围。这里没有测量口语自然度，更没有测试语音模型或真实业务系统。

下一轮最值得先改的是评测：让生成预算足够、将格式遵循与答案内容分开报告，再用不同表述和题型检验能否迁移。确认评测口径后，才适合进一步比较监督预算。
